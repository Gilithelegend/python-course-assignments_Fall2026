# Day 01

## What I did

Built a personal website at [gilithelegend.github.io](https://gilithelegend.github.io), generated by GitHub Pages (Jekyll) from a repository with 4 files:

- `README.md` – my content, written in Markdown (headings, bold, bullets). Jekyll converts it to HTML.
- `_config.yml` – site settings: `title`, `theme: jekyll-theme-minimal`, and `logo` (my photo).
- `assets/css/style.scss` – custom styling. Imports the theme first, then my rules on top: Open Sans font, larger text (18px) with 1.6 line spacing, flexbox layout so sidebar and text sit side by side, round 220px photo, hidden footer.
- `gk.jpeg` – my photo in the repo root.

Workflow: edit on GitHub → Commit changes → GitHub rebuilds the site (~1 min) → hard-refresh.

## Problems I hit and fixed

- Photo didn't show – first upload was a 2-byte text file ("Create new file"). Fixed with "Upload files" and matching the filename in `_config.yml`.
- Sidebar overlapped the text – theme uses `position: fixed`; replaced with flexbox.
- Name was huge – `font-size: 3em` on both `h1` and the link inside it multiplied. Put size on `h1`, color on `h1 a`.
- Duplicate CSS rules – cleaned up to one block per selector.

## What I learned

1. Markdown = content, CSS = looks, `_config.yml` = settings.
2. Later CSS rules override earlier ones, so my file imports the theme first.
3. Check the Actions tab for a green ✓ when the site doesn't update.
